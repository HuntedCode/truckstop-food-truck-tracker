# Brand Ownership Plan — Chuckwagon

> How we secure the name "Chuckwagon" in the places that matter. Updated 2026-06-06.
> Status legend: ☐ to do · ◐ in progress · ☑ done. Update as we claim each asset.

**Chuckwagon** is a real word (a chuckwagon is the 1866 horse-drawn mobile field kitchen, "America's first food truck"), so unlike a coined name it lives in a populated field. The sweep found:

- **The app/software lane is clear:** no food-truck-finder app or tech product uses "Chuckwagon" (the competitors are StreetFoodFinder, TruckSpotting, Truckster, etc.).
- **USPTO:** only two marks, both *entertainment* ("The Chuckwagon Channel", "Chuckwagon Association of the West"), none in software (class 9/42) or food-discovery. The lane we'd actually file in is open.
- **Crowded in food-service *names*:** many restaurants, BBQ joints, food-truck parks, and caterers use "Chuck Wagon"/"Chuckwagon". So `chuckwagon.com` and the clean `@chuckwagon` handle were taken, and the bare term is hard to own broadly. We lean into the **app** to differentiate.

### Trademark — deferred (decision stands)

**Decision: wait** until there's real traction/revenue (and ideally **before a public launch / press push**), to conserve capital. Lower-risk because using "Chuckwagon" in commerce builds common-law rights meanwhile.

**When we revisit:**
- **Mark:** `CHUCKWAGON` as a **standard character mark** (protects the word in any font/color).
- **Basis:** **intent-to-use (1b)** to lock priority before launch.
- **Classes:** **9** (downloadable app) + **42** (SaaS) as the core; **35** (marketplace/advertising for food trucks) optional.
- **Important nuance for this name:** the *software* lane is clear (only entertainment marks exist), which is encouraging, but "chuckwagon" is a common, widely-used food-service term, so the mark is best pursued in the **software class** and a **professional clearance before filing** is well worth it here (more so than it would be for a coined word). Cost ~$250–350/class + optional ~$150–600 for a service/attorney.
